# Simple Past

> **Legenda de cores:** <span style="color:#3b82f6">azul = sujeito</span> · <span style="color:#22c55e">verde = verbo/ação</span> · <span style="color:#eab308">amarelo = complemento/detalhe</span>

Usado para ações **terminadas** no passado. Equivale ao nosso pretérito perfeito: *fiz, trabalhei, fui, escrevi*.

## Fórmula

```
AFIRMATIVA:    Sujeito + verbo no passado
NEGATIVA:      Sujeito + did not (didn't) + verbo no INFINITIVO
INTERROGATIVA: Did + sujeito + verbo no INFINITIVO ?
```

`did` = *did* · `didn't` = *<span style="color:#ef4444">dí</span>dânt*

**A regra de ouro:** com `did` / `didn't`, o verbo volta para a forma base.

| | Exemplo | Pronúncia | Português |
|---|---|---|---|
| ✅ | <span style="color:#3b82f6">I</span> <span style="color:#22c55e">worked</span> <span style="color:#eab308">yesterday</span>. | *ái uôrkt <span style="color:#ef4444">iés</span>terdei* | Eu trabalhei ontem. |
| ✅ | <span style="color:#3b82f6">I</span> <span style="color:#22c55e">didn't work</span> <span style="color:#eab308">yesterday</span>. | *ái <span style="color:#ef4444">dí</span>dânt uôrk <span style="color:#ef4444">iés</span>terdei* | Eu não trabalhei ontem. |
| ❌ | ~~I didn't worked yesterday.~~ | | |
| ✅ | **Did** <span style="color:#3b82f6">you</span> <span style="color:#22c55e">work</span> <span style="color:#eab308">yesterday</span>? | *did iú uôrk <span style="color:#ef4444">iés</span>terdei* | Você trabalhou ontem? |
| ❌ | ~~Did you worked yesterday?~~ | | |

> ⚠️ **Erro comum:** dobrar o passado. O `did` já carrega o passado — o verbo principal fica no infinitivo.
> ~~*He didn't went*~~ → **He didn't go** (*rí <span style="color:#ef4444">dí</span>dânt gôu*).
> ~~*Did she made it?*~~ → **Did she make it?** (*did chí mêik it*).

## Verbos regulares: só adicionar -ed

| Regra | Exemplo | Pronúncia |
|---|---|---|
| padrão: + **-ed** | work → work**ed** | *uôrkt* |
| | deploy → deploy**ed** | *di<span style="color:#ef4444">plóid</span>* |
| | fix → fix**ed** | *fikst* |
| termina em **-e**: + **-d** | create → create**d** | *kri<span style="color:#ef4444">êi</span>tid* |
| | use → use**d** | *iúzd* |
| | close → close**d** | *clôuzd* |
| consoante + **-y**: y → **-ied** | try → tr**ied** | *tráid* |
| | apply → appl**ied** | *â<span style="color:#ef4444">pláid</span>* |
| | copy → cop**ied** | *<span style="color:#ef4444">có</span>pid* |
| 1 sílaba, consoante final: dobra | stop → sto**pped** | *stópt* |
| | plan → pla**nned** | *plénd* |
| | drop → dro**pped** | *drópt* |

### Pronúncia do -ed (3 sons) — o ponto mais importante

| Som | Quando usar | Exemplos |
|---|---|---|
| **/t/** (*t*) | após som surdo: p, k, f, s, ch, sh, x | worked (*uôrkt*), stopped (*stópt*), fixed (*fikst*), watched (*uótcht*) |
| **/d/** (*d*) | após som sonoro: b, g, v, l, m, n, r, vogal | called (*cóld*), used (*iúzd*), opened (*<span style="color:#ef4444">ôu</span>pând*), played (*plêid*) |
| **/ɪd/** (*id*) | **só** após **t** ou **d** | wanted (*<span style="color:#ef4444">uón</span>tid*), needed (*<span style="color:#ef4444">ní</span>ded*), started (*<span style="color:#ef4444">stár</span>tid*), created (*kri<span style="color:#ef4444">êi</span>tid*) |

> ⚠️ **Erro comum de brasileiro:** pronunciar tudo como "-édi" (*uork-<span style="color:#ef4444">é</span>di*). Na maioria dos casos o `-ed` **não vira sílaba nova**: `worked` tem **1 sílaba só** (*uôrkt*). Só vira sílaba quando o verbo termina em **t** ou **d**.

## Verbos irregulares: não seguem regra

Precisam ser decorados. Ver [[verbos-irregulares]].

| Base → passado | Frase (cores) | Pronúncia | Português |
|---|---|---|---|
| go → went (*uênt*) | <span style="color:#3b82f6">I</span> <span style="color:#22c55e">went</span> <span style="color:#eab308">to the office</span>. | *ái uênt tu di ófis* | Eu fui ao escritório. |
| have → had (*réd*) | <span style="color:#3b82f6">We</span> <span style="color:#22c55e">had</span> <span style="color:#eab308">a meeting</span>. | *uí réd â míting* | Nós tivemos uma reunião. |
| make → made (*mêid*) | <span style="color:#3b82f6">She</span> <span style="color:#22c55e">made</span> <span style="color:#eab308">a mistake</span>. | *chí mêid â mistêik* | Ela cometeu um erro. |

## O verbo TO BE é a exceção

`to be` no passado **não usa `did`**:

| Sujeito | Passado | Pronúncia |
|---|---|---|
| I / he / she / it | **was** | *uâz* |
| you / we / they | **were** | *uârr* |

| | Exemplo | Pronúncia |
|---|---|---|
| Afirmativa | <span style="color:#3b82f6">I</span> <span style="color:#22c55e">was</span> <span style="color:#eab308">tired</span>. | *ái uâz <span style="color:#ef4444">tái</span>ârd* |
| | <span style="color:#3b82f6">They</span> <span style="color:#22c55e">were</span> <span style="color:#eab308">here</span>. | *dêi uârr rír* |
| Negativa | <span style="color:#3b82f6">I</span> <span style="color:#22c55e">wasn't</span> <span style="color:#eab308">tired</span>. | *ái <span style="color:#ef4444">uâ</span>zânt <span style="color:#ef4444">tái</span>ârd* |
| | <span style="color:#3b82f6">They</span> <span style="color:#22c55e">weren't</span> <span style="color:#eab308">here</span>. | *dêi <span style="color:#ef4444">uâ</span>rânt rír* |
| Pergunta | **Was** <span style="color:#3b82f6">he</span> <span style="color:#eab308">there</span>? | *uâz rí dêr* |
| | **Were** <span style="color:#3b82f6">you</span> <span style="color:#eab308">there</span>? | *uârr iú dêr* |

> ⚠️ **Erro comum:** ~~*Did you was there?*~~ → **Were you there?** (*uârr iú dêr*).

> ⚠️ **Erro comum de pronúncia:** `was` não é "uós", é ***uâz*** (com z no final). `were` não é "u<span style="color:#ef4444">é</span>re", é ***uârr***.

## Marcadores de tempo que pedem Simple Past

| Marcador | Pronúncia | Português |
|---|---|---|
| yesterday | *<span style="color:#ef4444">iés</span>terdei* | ontem |
| last night / week / month | *lést náit / uík / mânth* | ontem à noite / semana passada / mês passado |
| two days ago | *tchu dêiz â<span style="color:#ef4444">gôu</span>* | dois dias atrás |
| in 2020 | *in <span style="color:#ef4444">tchuen</span>ti-<span style="color:#ef4444">tchuen</span>ti* | em 2020 |
| when I was a kid | *uên ái uâz â kid* | quando eu era criança |

|---|---|

| <span style="color:#3b82f6">She</span> <span style="color:#22c55e">joined</span> <span style="color:#eab308">the team two years ago</span>. | *chí djóind dâ tím tchu iârz â<span style="color:#ef4444">gôu</span>* |
