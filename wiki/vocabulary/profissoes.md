# Profissões (jobs) + adjetivos de personalidade

> **Legenda de cores:** <span style="color:#3b82f6">azul = sujeito</span> · <span style="color:#22c55e">verde = verbo/ação</span> · <span style="color:#eab308">amarelo = complemento/detalhe</span>

Uso com o verbo **be**: veja [[verbo-be-pronomes]]. Ordem *adjetivo + profissão*: [[ordem-adjetivo-substantivo]]. Escolha de a/an: [[artigos-a-an]].

## 🧠 Mindmap

```text
Jobs
├── Saúde: doctor = médico · nurse = enfermeiro
├── Educação: teacher = professor · student = estudante
├── Lei e segurança: lawyer = advogado · police officer = policial
├── Negócios: businessman = empresário · saleswoman = vendedora
└── Técnico e serviço: engineer = engenheiro · mailman = carteiro
```
## Profissões

| Escrito | Pronúncia | Significado | Contexto / curiosidade |
|---------|-----------|-------------|------------------------|
| **student** | *(<span style="color:#ef4444">stiú</span>dent)* | estudante | serve de escola a faculdade |
| **teacher** | *(<span style="color:#ef4444">tí</span>tcher)* | professor(a) | *teach* (títch) = ensinar + **-er** = quem faz |
| **doctor** | *(<span style="color:#ef4444">dóc</span>tor)* | médico(a) | também é título: *Dr. Silva* |
| **nurse** | *(nârs)* | enfermeiro(a) | mesma palavra para homem e mulher |
| **police officer** | *(po<span style="color:#ef4444">líss</span> <span style="color:#ef4444">ó</span>fisser)* | policial | mais neutro que *policeman* |
| **lawyer** | *(<span style="color:#ef4444">lói</span>er)* | advogado(a) | *law* (ló) = lei |
| **businessman** | *(<span style="color:#ef4444">bíz</span>nis-man)* | empresário | feminino: *businesswoman* (<span style="color:#ef4444">bíz</span>nis-uóman) |
| **saleswoman** | *(<span style="color:#ef4444">séils</span>-uóman)* | vendedora | masculino: *salesman*; neutro: *salesperson* |
| **engineer** | *(endjí<span style="color:#ef4444">nír</span>)* | engenheiro(a) | no trabalho de dev: *software engineer* |
| **mailman** | *(<span style="color:#ef4444">méil</span>-man)* | carteiro | *mail* (méil) = correio |

💡 *Comparação com o português:* em inglês **não existe flexão de gênero** na maioria das profissões: *a teacher* = professor **ou** professora. Só aparece em *-man / -woman*.

💡 *Família de palavras:* **-er / -or** (quem faz): *teach → teacher*, *act → actor*. Mesma ideia do "-dor" em português (*vendedor*).

> ⚠️ Erro comum: **engineer** não se pronuncia "engenhêr". A tônica cai na **última** sílaba: *endjiNÍR*.

## Adjetivos de personalidade

| Escrito | Pronúncia | Significado | Oposto |
|---------|-----------|-------------|--------|
| **smart** | *(smárt)* | inteligente | **dumb** |
| **intelligent** | *(in<span style="color:#ef4444">té</span>lidjent)* | inteligente (mais formal) | **stupid** |
| **dumb** | *(dâm)* | burro, tonto | **smart** |
| **stupid** | *(<span style="color:#ef4444">stiú</span>pid)* | estúpido, burro | **intelligent** |
| **young** | *(iâng)* | jovem | **old** (ôld) |
| **silly** | *(<span style="color:#ef4444">sí</span>li)* | bobo, tolo (leve, até carinhoso) | **serious** (<span style="color:#ef4444">sí</span>riâs) |
| **kind** | *(káind)* | gentil | **rude** (rúd) |
| **grumpy** | *(<span style="color:#ef4444">grâm</span>pi)* | mal-humorado | **cheerful** (<span style="color:#ef4444">tchír</span>ful) |
| **friendly** | *(<span style="color:#ef4444">frénd</span>li)* | simpático, amigável | **unfriendly** (ân<span style="color:#ef4444">frénd</span>li) |

> ⚠️ **Registro:** *dumb* e *stupid* são **ofensivos** quando dirigidos a uma pessoa real ("You are stupid" é insulto). Em aula servem para treinar vocabulário; na vida real prefira *silly* (leve) ou *not very smart*.

## Adjetivo + profissão

Fórmula: `a/an + adjetivo + profissão` (o adjetivo vem **antes**, ao contrário do português).

<span style="color:#3b82f6">She</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">a smart doctor</span>. *(xí iz â smárt <span style="color:#ef4444">dóc</span>tor)* — Ela é uma médica inteligente.

<span style="color:#3b82f6">He</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">a young lawyer</span>. *(rí iz â iâng <span style="color:#ef4444">lói</span>er)* — Ele é um advogado jovem.

<span style="color:#3b82f6">He</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">a friendly mailman</span>. *(rí iz â <span style="color:#ef4444">frénd</span>li <span style="color:#ef4444">méil</span>-man)* — Ele é um carteiro simpático.

<span style="color:#3b82f6">I</span> <span style="color:#22c55e">am</span> <span style="color:#eab308">an intelligent student</span>. *(ái ém ân in<span style="color:#ef4444">té</span>lidjent <span style="color:#ef4444">stiú</span>dent)* — Eu sou um estudante inteligente.

### a ou an?

> ⚠️ Erro comum: o artigo depende da palavra **imediatamente depois**. *a **y**oung lawyer* (iâng = som de consoante), mas *an **i**ntelligent lawyer*.

## Praticar

1. Complete: He is ___ intelligent student. → *an*
2. Traduza: Ela é uma enfermeira simpática. → *She is a friendly nurse.*
3. Qual é o oposto de *smart*? → *dumb*
