# Pronomes demonstrativos: this/that/these/those

> **Legenda de cores:** <span style="color:#3b82f6">azul = sujeito</span> · <span style="color:#22c55e">verde = verbo/ação</span> · <span style="color:#eab308">amarelo = complemento/detalhe</span>

Material "Word It Up" (Overcome Idiomas) — como perguntar "o que é isto?" e responder, no singular e no plural.

## A regra

| Escrito | Pronúncia | Significado | Uso |
|---|---|---|---|
| this | *dis* | isto/isso | pergunta, singular |
| it | *it* | ele/ela | resposta, singular |
| these | *díz* | estes/estas | pergunta, plural |
| they | *dêi* | eles/elas | resposta, plural |

`this/it` pedem **is**. `these/they` pedem **are**.

## Exemplos

<span style="color:#3b82f6">What</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">this</span>? — <span style="color:#3b82f6">It</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">a sticky tape</span>.
*(uót iz dis? — it iz â st<span style="color:#ef4444">í</span>ki téip)* — O que é isto? É uma fita adesiva.

<span style="color:#3b82f6">What</span>'s <span style="color:#eab308">this</span>? — <span style="color:#3b82f6">It</span>'s <span style="color:#eab308">an eraser</span>.
*(uóts dis? — its ân i<span style="color:#ef4444">rei</span>zâr)* — O que é isto? É uma borracha.

<span style="color:#3b82f6">What</span> <span style="color:#22c55e">are</span> <span style="color:#eab308">these</span>? — <span style="color:#3b82f6">They</span> <span style="color:#22c55e">are</span> <span style="color:#eab308">pencils</span>.
*(uót ár díz? — dêi ár p<span style="color:#ef4444">én</span>sâls)* — O que são estes? São lápis.

**Contração:** "It is" → **It's** *(its)*, "They are" → **They're** *(dêiâr)*. Nativos quase sempre contraem na fala.

**Contexto de uso:** essa é a estrutura clássica de "flashcard" — apontar pra um objeto e perguntar o que é. Aparece o tempo todo em conversas simples de identificação de objetos.

## O quarteto completo: perto vs longe

O material só cobriu `this/these` (objeto **perto**), mas existe o par equivalente pra objeto **longe** — sem isso a regra fica pela metade.

| Escrito | Pronúncia | Significado | Distância |
|---|---|---|---|
| this | *dis* | isto/isso | perto, singular |
| that | *dhét* | aquilo | longe, singular |
| these | *díz* | estes/estas | perto, plural |
| those | *dhôuz* | aqueles/aquelas | longe, plural |

<span style="color:#3b82f6">What</span><span style="color:#22c55e">'s</span> <span style="color:#eab308">that</span>? — <span style="color:#3b82f6">It</span><span style="color:#22c55e">'s</span> <span style="color:#eab308">a whiteboard</span> (over there).
*(uóts dhét? — its â uáitbôrd)* — O que é aquilo? É um quadro branco (lá longe).

<span style="color:#3b82f6">What</span> <span style="color:#22c55e">are</span> <span style="color:#eab308">those</span>? — <span style="color:#3b82f6">They</span><span style="color:#22c55e">'re</span> <span style="color:#eab308">staples</span>.
*(uót ár dhôuz? — dhêiâr stéiplâs)* — O que são aqueles? São grampos.

**Comparação com o português:** em português "isso" e "aquilo" já fazem essa distinção de distância — a diferença é que o inglês também muda o **plural** (these/those), coisa que o português não marca de forma tão rígida.

> ⚠️ Erro comum: confundir "that" (dhét, com TH) com "what" (uót). Visualmente parecidas, mas o "th" de "that" é dental (língua entre os dentes) e não existe em português — não é nem "d" nem "f".

## Plural obrigatório (peças de duas partes)

`jeans`, `sunglasses`, `glasses`, `pants`, `scissors` são sempre plural — sempre usam **these/they are**, nunca "this/it is". Detalhes em [[substantivos-plural]].

<span style="color:#3b82f6">These</span> <span style="color:#22c55e">are</span> <span style="color:#eab308">my jeans</span>. *(díz ár mái djínz)* — Esta é minha calça jeans.

<span style="color:#3b82f6">Are</span> <span style="color:#eab308">these</span> <span style="color:#eab308">your sunglasses</span>? *(ár díz iór s<span style="color:#ef4444">ân</span>glesiz?)* — Estes são seus óculos de sol?

<span style="color:#3b82f6">These</span> <span style="color:#22c55e">aren't</span> <span style="color:#eab308">my glasses</span>. *(díz árânt mái gl<span style="color:#ef4444">és</span>iz)* — Estes não são meus óculos.

> ⚠️ Erro comum: "scissors" é sempre plural — nunca "a scissor" ou "this scissor". Ver [[objetos-de-escritorio]] para o vocabulário completo de escritório.
