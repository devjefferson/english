# Adjetivos descritivos básicos

> **Legenda de cores:** <span style="color:#3b82f6">azul = sujeito</span> · <span style="color:#22c55e">verde = verbo/ação</span> · <span style="color:#eab308">amarelo = complemento/detalhe</span>

10 pares adjetivo + substantivo, do material "Word It Up" (Overcome Idiomas).

| Frase | Pronúncia | Significado (PT) |
|---|---|---|
| an independent country | *ân indi<span style="color:#ef4444">pên</span>dent <span style="color:#ef4444">cân</span>tri* | um país independente |
| an organized city | *ân <span style="color:#ef4444">ór</span>ganáizd <span style="color:#ef4444">si</span>ti* | uma cidade organizada |
| a vast continent | *â vést <span style="color:#ef4444">cón</span>tinent* | um continente vasto |
| a foreign language | *â <span style="color:#ef4444">fó</span>rin <span style="color:#ef4444">léng</span>üidj* | uma língua estrangeira |
| a bright color | *â bráit <span style="color:#ef4444">câ</span>lâr* | uma cor brilhante |
| a noisy insect | *â <span style="color:#ef4444">nói</span>zi <span style="color:#ef4444">ín</span>sect* | um inseto barulhento |
| a slow animal | *â slôu <span style="color:#ef4444">é</span>nimâl* | um animal lento |
| a fast machine | *â fést mâ<span style="color:#ef4444">chín</span>* | uma máquina rápida |
| an easy sport | *ân <span style="color:#ef4444">í</span>zi spórt* | um esporte fácil |
| a difficult thing | *â <span style="color:#ef4444">dí</span>ficâlt thíng* | uma coisa difícil |

## Exemplos de frase

| Frase (cores) | Pronúncia | Português |
|---|---|---|
| <span style="color:#3b82f6">Brazil</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">an independent country</span>. | *brâ<span style="color:#ef4444">zíu</span> iz ân indi<span style="color:#ef4444">pên</span>dent <span style="color:#ef4444">cân</span>tri* | O Brasil é um país independente. |
| <span style="color:#3b82f6">Basketball</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">an easy sport to learn</span>. | *<span style="color:#ef4444">bés</span>kitbol iz ân <span style="color:#ef4444">í</span>zi spórt tu lârn* | Basquete é um esporte fácil de aprender. |
| <span style="color:#3b82f6">Learning a foreign language</span> <span style="color:#22c55e">takes</span> <span style="color:#eab308">time</span>. | *<span style="color:#ef4444">lâr</span>ning â <span style="color:#ef4444">fó</span>rin <span style="color:#ef4444">léng</span>üidj têiks táim* | Aprender uma língua estrangeira leva tempo. |

## Adjetivos opostos (para praticar substituição)

| Adjetivo | Pronúncia | Oposto | Pronúncia |
|---|---|---|---|
| independent | *indi<span style="color:#ef4444">pên</span>dent* | dependent | *di<span style="color:#ef4444">pên</span>dent* |
| organized | *<span style="color:#ef4444">ór</span>ganáizd* | messy / chaotic | *<span style="color:#ef4444">mês</span>si / kei<span style="color:#ef4444">ó</span>tic* |
| vast | *vést* | small | *smól* |
| foreign | *<span style="color:#ef4444">fó</span>rin* | native / local | *<span style="color:#ef4444">nêi</span>tiv / <span style="color:#ef4444">lôu</span>câl* |
| bright | *bráit* | dull | *dâl* |
| noisy | *<span style="color:#ef4444">nói</span>zi* | quiet | *<span style="color:#ef4444">quái</span>ât* |
| slow | *slôu* | fast | *fést* |
| fast | *fést* | slow | *slôu* |
| easy | *<span style="color:#ef4444">í</span>zi* | difficult / hard | *<span style="color:#ef4444">dí</span>ficâlt / rárd* |
| difficult | *<span style="color:#ef4444">dí</span>ficâlt* | easy | *<span style="color:#ef4444">í</span>zi* |

> ⚠️ **Erro comum:** confundir "foreign" (*<span style="color:#ef4444">fó</span>rin* — estrangeiro/de outro país) com "unknown" (*â<span style="color:#ef4444">nôun</span>* — desconhecido). Não são sinônimos.
