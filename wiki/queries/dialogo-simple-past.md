# Diálogo — Simple Past

> **Legenda de cores:** <span style="color:#3b82f6">azul = sujeito</span> · <span style="color:#22c55e">verde = verbo/ação</span> · <span style="color:#eab308">amarelo = complemento/detalhe</span>

Dois diálogos curtos para praticar [[simple-past]] e [[verbos-irregulares]]. Leia em voz alta seguindo a pronúncia em itálico.

---

## Diálogo 1 — Segunda-feira no trabalho

**Sarah:** Hi Jefferson! How <span style="color:#22c55e">was</span> <span style="color:#eab308">your weekend</span>?
*rái <span style="color:#ef4444">djé</span>ferson! ráu uôz iór <span style="color:#ef4444">uí</span>kend?*
→ Oi Jefferson! Como foi seu fim de semana?

**Jefferson:** <span style="color:#3b82f6">It</span> <span style="color:#22c55e">was</span> <span style="color:#eab308">great, thanks</span>. <span style="color:#3b82f6">I</span> <span style="color:#22c55e">went</span> <span style="color:#eab308">to the beach with my family</span>.
*it uôz grêit, thénks. ái uênt tu dê bítch uíth mái <span style="color:#ef4444">fé</span>mili*
→ Foi ótimo, obrigado. Eu fui à praia com minha família.

**Sarah:** Nice! **Did** <span style="color:#3b82f6">you</span> <span style="color:#22c55e">take</span> <span style="color:#eab308">any pictures</span>?
*náis! did iú têik <span style="color:#ef4444">ê</span>ni <span style="color:#ef4444">píkt</span>chârs?*
→ Legal! Você tirou fotos?

**Jefferson:** Yes, <span style="color:#3b82f6">I</span> <span style="color:#22c55e">took</span> <span style="color:#eab308">a lot</span>. And you? What **did** <span style="color:#3b82f6">you</span> <span style="color:#22c55e">do</span>?
*iés, ái túk â lót. end iú? uót did iú dú?*
→ Sim, tirei muitas. E você? O que você fez?

**Sarah:** <span style="color:#3b82f6">I</span> <span style="color:#22c55e">stayed</span> <span style="color:#eab308">home</span>. <span style="color:#3b82f6">I</span> <span style="color:#22c55e">didn't go</span> <span style="color:#eab308">out</span> — <span style="color:#3b82f6">I</span> <span style="color:#22c55e">was</span> <span style="color:#eab308">very tired</span>.
*ái stêid rôum. ái <span style="color:#ef4444">dí</span>dânt gôu áut — ái uôz <span style="color:#ef4444">vé</span>ri <span style="color:#ef4444">tái</span>ârd*
→ Fiquei em casa. Não saí — eu estava muito cansada.

**Jefferson:** <span style="color:#3b82f6">I</span> <span style="color:#22c55e">understand</span>. <span style="color:#3b82f6">Last week</span> <span style="color:#22c55e">was</span> <span style="color:#eab308">hard for everyone</span>.
*ái ândârs<span style="color:#ef4444">tênd</span>. lést uík uôz rárd for <span style="color:#ef4444">é</span>vriuân*
→ Eu entendo. A semana passada foi difícil para todos.

## Diálogo 2 — Daily meeting (tech)

**Lead:** Good morning. What **did** <span style="color:#3b82f6">you</span> <span style="color:#22c55e">work</span> <span style="color:#eab308">on yesterday</span>?
*gud <span style="color:#ef4444">mór</span>nin. uót did iú uôrk ón <span style="color:#ef4444">iés</span>terdei?*
→ Bom dia. No que você trabalhou ontem?

**Jefferson:** <span style="color:#3b82f6">I</span> <span style="color:#22c55e">fixed</span> <span style="color:#eab308">the login bug</span> and <span style="color:#22c55e">wrote</span> <span style="color:#eab308">the tests</span>.
*ái fikst dê <span style="color:#ef4444">ló</span>guin bâg end rôut dê tésts*
→ Eu corrigi o bug do login e escrevi os testes.

**Lead:** **Did** <span style="color:#3b82f6">you</span> <span style="color:#22c55e">deploy</span> <span style="color:#eab308">it to production</span>?
*did iú di<span style="color:#ef4444">plói</span> it tu prâ<span style="color:#ef4444">dâk</span>chân?*
→ Você fez o deploy para produção?

**Jefferson:** Not yet. <span style="color:#3b82f6">The build</span> <span style="color:#22c55e">failed</span>, so <span style="color:#3b82f6">I</span> <span style="color:#22c55e">didn't deploy</span>.
*nót iét. dê bíld fêild, sôu ái <span style="color:#ef4444">dí</span>dânt di<span style="color:#ef4444">plói</span>*
→ Ainda não. O build falhou, então eu não fiz o deploy.

**Lead:** What <span style="color:#22c55e">happened</span>?
*uót <span style="color:#ef4444">ré</span>pând?*
→ O que aconteceu?

**Jefferson:** <span style="color:#3b82f6">A test</span> <span style="color:#22c55e">broke</span> <span style="color:#eab308">after the merge</span>. <span style="color:#3b82f6">I</span> <span style="color:#22c55e">found</span> <span style="color:#eab308">the problem</span>, but <span style="color:#3b82f6">I</span> <span style="color:#22c55e">didn't have</span> <span style="color:#eab308">time to fix it</span>.
*â tést brôuk <span style="color:#ef4444">éf</span>ter dê mêrdj. ái fáund dê <span style="color:#ef4444">pró</span>blem, bât ái <span style="color:#ef4444">dí</span>dânt rév táim tu fiks it*
→ Um teste quebrou depois do merge. Eu achei o problema, mas não tive tempo de corrigir.

**Lead:** OK. **Did** <span style="color:#3b82f6">you</span> <span style="color:#22c55e">open</span> <span style="color:#eab308">an issue</span>?
*ôu<span style="color:#ef4444">kêi</span>. did iú <span style="color:#ef4444">ôu</span>pân ên <span style="color:#ef4444">í</span>chu?*
→ Ok. Você abriu uma issue?

**Jefferson:** Yes, <span style="color:#3b82f6">I</span> <span style="color:#22c55e">created</span> <span style="color:#eab308">one</span> and <span style="color:#22c55e">sent</span> <span style="color:#eab308">the link to the team</span>.
*iés, ái kri<span style="color:#ef4444">êi</span>tid uân end sént dê link tu dê tím*
→ Sim, criei uma e mandei o link para o time.

## Verbos usados nos diálogos

| Infinitivo | Pronúncia | Passado | Pronúncia | Português |
| ---------- | --------- | ------- | --------- | --------- |
| be | *bí* | was / were | *uôz / uêr* | ser, estar |
| go | *gôu* | went | *uênt* | ir |
| take | *têik* | took | *túk* | pegar, tirar |
| do | *dú* | did | *did* | fazer |
| stay | *stêi* | stayed | *stêid* | ficar |
| understand | *ândârs<span style="color:#ef4444">tênd</span>* | understood | *ândârs<span style="color:#ef4444">túd</span>* | entender |
| work | *uôrk* | worked | *uôrkt* | trabalhar |
| fix | *fiks* | fixed | *fikst* | corrigir |
| write | *ráit* | wrote | *rôut* | escrever |
| deploy | *di<span style="color:#ef4444">plói</span>* | deployed | *di<span style="color:#ef4444">plóid</span>* | publicar, subir |
| fail | *fêiu* | failed | *fêild* | falhar |
| happen | *<span style="color:#ef4444">ré</span>pân* | happened | *<span style="color:#ef4444">ré</span>pând* | acontecer |
| break | *brêik* | broke | *brôuk* | quebrar |
| find | *fáind* | found | *fáund* | achar, encontrar |
| have | *rév* | had | *réd* | ter |
| open | *<span style="color:#ef4444">ôu</span>pân* | opened | *<span style="color:#ef4444">ôu</span>pând* | abrir |
| create | *kri<span style="color:#ef4444">êit</span>* | created | *kri<span style="color:#ef4444">êi</span>tid* | criar |
| send | *sénd* | sent | *sént* | enviar |

> ⚠️ **Erro comum:** depois de `did` / `didn't`, o verbo **nunca** vai para o passado.
> ~~*I didn't deployed*~~ → **I didn't deploy** (*ái <span style="color:#ef4444">dí</span>dânt di<span style="color:#ef4444">plói</span>*).
> ~~*Did you took pictures?*~~ → **Did you take pictures?** (*did iú têik <span style="color:#ef4444">píkt</span>chârs*).
