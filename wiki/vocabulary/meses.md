# Months — meses

> **Legenda de cores:** <span style="color:#3b82f6">azul = sujeito</span> · <span style="color:#22c55e">verde = verbo/ação</span> · <span style="color:#eab308">amarelo = complemento/detalhe</span>

| Inglês | Pronúncia | PT |
|---|---|---|
| January | *<span style="color:#ef4444">djé</span>nueri* | janeiro |
| February | *<span style="color:#ef4444">fé</span>brueri* | fevereiro |
| March | *mártch* | março |
| April | *<span style="color:#ef4444">êi</span>prâl* | abril |
| May | *mêi* | maio |
| June | *djún* | junho |
| July | *dju<span style="color:#ef4444">lái</span>* | julho |
| August | *<span style="color:#ef4444">ó</span>gâst* | agosto |
| September | *sep<span style="color:#ef4444">têm</span>bâr* | setembro |
| October | *ôu<span style="color:#ef4444">tôu</span>bâr* | outubro |
| November | *nôu<span style="color:#ef4444">vêm</span>bâr* | novembro |
| December | *di<span style="color:#ef4444">sêm</span>bâr* | dezembro |

> ⚠️ **Erro comum:** assim como os dias da semana, meses são **sempre maiúsculos** em inglês. ~~*born in march*~~ → **born in March**.
