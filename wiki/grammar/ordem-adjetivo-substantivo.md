# Ordem: adjetivo antes do substantivo

> **Legenda de cores:** <span style="color:#3b82f6">azul = sujeito</span> · <span style="color:#22c55e">verde = verbo/ação</span> · <span style="color:#eab308">amarelo = complemento/detalhe</span> (adjetivo+substantivo entram como complemento)

Em português o adjetivo geralmente vem **depois** do substantivo ("país independente"). Em inglês, é o **contrário**: o adjetivo vem **antes**.

## Fórmula

```
(artigo) + ADJETIVO + SUBSTANTIVO
```

| Português (subst. + adj.) | Inglês (adj. + subst.) | Pronúncia |
|---|---|---|
| um país independente | **an independent country** | *ân indi<span style="color:#ef4444">pên</span>dent <span style="color:#ef4444">cân</span>tri* |
| uma cidade organizada | **an organized city** | *ân <span style="color:#ef4444">ór</span>ganáizd <span style="color:#ef4444">si</span>ti* |
| um continente vasto | **a vast continent** | *â vést <span style="color:#ef4444">cón</span>tinent* |
| uma língua estrangeira | **a foreign language** | *â <span style="color:#ef4444">fó</span>rin <span style="color:#ef4444">lén</span>güidj* |
| uma cor brilhante | **a bright color** | *â bráit <span style="color:#ef4444">câ</span>lâr* |
| um inseto barulhento | **a noisy insect** | *â <span style="color:#ef4444">nói</span>zi <span style="color:#ef4444">ín</span>sect* |
| um animal lento | **a slow animal** | *â slôu <span style="color:#ef4444">é</span>nimâl* |
| uma máquina rápida | **a fast machine** | *â fést mâ<span style="color:#ef4444">chín</span>* |
| um esporte fácil | **an easy sport** | *ân <span style="color:#ef4444">í</span>zi spórt* |
| uma coisa difícil | **a difficult thing** | *â <span style="color:#ef4444">dí</span>ficâlt thíng* |

## Em frase completa

| Frase (cores) | Pronúncia | Português |
|---|---|---|
| <span style="color:#3b82f6">Brazil</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">an independent country</span>. | *brâ<span style="color:#ef4444">zíu</span> iz ân indi<span style="color:#ef4444">pên</span>dent <span style="color:#ef4444">cân</span>tri* | O Brasil é um país independente. |
| <span style="color:#3b82f6">English</span> <span style="color:#22c55e">is</span> <span style="color:#eab308">a foreign language</span> to me. | *<span style="color:#ef4444">ín</span>glich iz â <span style="color:#ef4444">fó</span>rin <span style="color:#ef4444">lén</span>güidj tu mi* | Inglês é uma língua estrangeira para mim. |

> ⚠️ **Erro comum:** montar a frase na ordem do português. ~~*a country independent*~~ → **an independent country** (*ân indi<span style="color:#ef4444">pên</span>dent <span style="color:#ef4444">cân</span>tri*).

> ⚠️ **Erro comum de pronúncia:** em "foreign" (*<span style="color:#ef4444">fó</span>rin*) o **g** é **mudo** — não se fala "fóreign" nem "fórign". Só duas sílabas: *<span style="color:#ef4444">fó</span>-rin*. Provavelmente por isso essa frase aparece destacada no material — é uma armadilha clássica de pronúncia, não de gramática.
