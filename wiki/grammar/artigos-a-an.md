# Artigos indefinidos: a / an

> Esta página trata de palavras isoladas (artigo + adjetivo + substantivo), sem sujeito/verbo — por isso não usa a codificação de 3 cores (ver [[ordem-adjetivo-substantivo]] para o mesmo conteúdo em frase completa e colorida).

Equivalem a "um/uma" em português, mas a escolha entre **a** e **an** depende do **som** da palavra seguinte — não da letra escrita.

## Regra

```
a  + palavra que começa com SOM DE CONSOANTE
an + palavra que começa com SOM DE VOGAL (a, e, i, o, u)
```

> ⚠️ **Erro comum:** olhar só a letra, não o som. `an hour` (*ân áuâr*) usa **an** porque o "h" é mudo (som de vogal), mas `a university` (*â iuni<span style="color:#ef4444">vér</span>citi*) usa **a** porque "u" aqui soa como "iú" (som de consoante /j/).

> ⚠️ **Erro comum de brasileiro:** usar "an" toda vez que o adjetivo "parece" começar com vogal na escrita, mesmo quando o som real é de consoante (ex.: confundir isso com "university", "european" — ambos usam **a**, não **an**, porque soam com /j/ no início).

## Exceção do H mudo

Em algumas palavras o "h" não tem som — a palavra soa como se começasse em vogal.

| Escrito | Pronúncia | Significado |
|---|---|---|
| an **h**onest man | ân <span style="color:#ef4444">ó</span>nest men | um homem honesto |
| an **h**our | ân <span style="color:#ef4444">áu</span>âr | uma hora |
| an **h**onor | ân <span style="color:#ef4444">ó</span>nâr | uma honra |
| an **h**erb | ân êrb | uma erva |

> ⚠️ **Erro comum:** ver "h" escrito e automaticamente usar **a**. Em `honest`, `hour`, `honor`, `herb` o h é mudo → soa como vogal → usa **an**.

## U tem dois sons diferentes

A pegadinha mais comum: "u" às vezes soa como **consoante** (/j/, "iú" — como em "you"), às vezes como **vogal pura** (/â/).

| U como CONSOANTE → usa **a** | Pronúncia                                                                           | U como VOGAL → usa **an** | Pronúncia                                           |
| ---------------------------- | ----------------------------------------------------------------------------------- | ------------------------- | --------------------------------------------------- |
| a **u**niform                | â <span style="color:#ef4444">iú</span>nifórm                                       | an **u**mbrella           | ân âm<span style="color:#ef4444">bré</span>lâ       |
| a **u**niverse               | â <span style="color:#ef4444">iú</span>nivêrs                                       | an **u**ncle              | ân <span style="color:#ef4444">ân</span>câl         |
| a **u**sed pencil            | â <span style="color:#ef4444">iúzd</span> <span style="color:#ef4444">pên</span>sil | an **u**pgrade            | ân <span style="color:#ef4444">âp</span>greid       |
| a **u**niversity             | â iuni<span style="color:#ef4444">vér</span>siti                                    | an **u**nderstanding      | ân ânders<span style="color:#ef4444">tén</span>ding |

> ⚠️ **Erro comum de brasileiro:** achar que toda palavra com "u" é `an`. Regra prática: se o "u" soa "**iú**" (como em "you"), é **a**. Se soa "**â**" puro, é **an**.
