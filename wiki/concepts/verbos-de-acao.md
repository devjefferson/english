# Verbos de ação — tech e cotidiano

> **Legenda de cores:** <span style="color:#3b82f6">azul = sujeito</span> · <span style="color:#22c55e">verde = verbo/ação</span> · <span style="color:#eab308">amarelo = complemento/detalhe</span>

Verbos são as palavras de ação. Em inglês, o verbo vem sempre depois do sujeito.
Fórmula básica: **Eu + verbo + objeto** → <span style="color:#3b82f6">I</span> <span style="color:#22c55e">delete</span> <span style="color:#eab308">the file</span> (Eu deleto o arquivo)

## Como usar no presente

Em inglês, o presente simples é muito direto:

| Português | Inglês (cores) |
|-----------|--------|
| Eu crio | <span style="color:#3b82f6">I</span> <span style="color:#22c55e">create</span> |
| Você cria | <span style="color:#3b82f6">You</span> <span style="color:#22c55e">create</span> |
| Ele/Ela cria | <span style="color:#3b82f6">He/She</span> <span style="color:#22c55e">creates</span> ← adiciona "s" |
| Nós criamos | <span style="color:#3b82f6">We</span> <span style="color:#22c55e">create</span> |
| Eles criam | <span style="color:#3b82f6">They</span> <span style="color:#22c55e">create</span> |

> ⚠️ **Erro comum:** esquecer o **-s** quando o sujeito é *he*, *she* ou *it*.
> ❌ *She create the file*
> ✅ *She create**s** the file*
